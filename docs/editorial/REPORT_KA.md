## 3. რას ქმნიან აგენტები რეალურად

- **ECHO-ს რედაქციის აგენტი (Claude Code, MCP):** კითხულობს მხოლოდ დამტკიცებულ და ავტორის მიერ გაზიარებულ მასალას (`get_editorial_packet`) და წერს სრულ რედაქციულ გეგმას (`submit_rundown`): მთავარი კითხვა, რატომ არის მნიშვნელოვანი, დაძაბულობა, ბლოკები და ხანგრძლივობა, წამყვანების რეპლიკები, ინტერვიუს კითხვები, ფაილების დანიშნულება, Q&A შესავალი, დასკვნა. ასევე შეუძლია მაყურებლის კითხვის **შეთავაზება** (shortlist) მიზეზით.
- **სტუმრის საკუთარი აგენტი (Codex, MCP):** მხოლოდ სტუმრის ნებართვით პასუხობს შერჩეულ კითხვას; პასუხი ეთერში აგენტის პასუხად მოიწერება.
- **სერვერის „გრაუნდინგის კარიბჭე“ (არა LLM):** ყოველ გეგმას ამოწმებს: ციტატა = ავტორის ზუსტი სიტყვები; ფაქტი = მხოლოდ ადამიანის მიერ გადამოწმებული ტექსტი; პაკეტში არარსებული რიცხვი, „კვლევა“, კანონი, სტატისტიკა, ბმული, ბრძანება — უარი; ნამუშევარი ზუსტად დადასტურებულ დროზე; სკეპტიკოსი ავტორის კონკრეტულ განცხადებას პასუხობს; ტექსტი წაკითხვადია (≤15 სიმბ./წმ); Q&A ბლოკი მაყურებლის კითხვას ვერ დაწერს და გეგმა ვერ იტყვის, რომ მაყურებელმა რამე იკითხა.
- **წესებზე დაფუძნებული დამგეგმავი (არა LLM):** დეტერმინისტული სათადარიგო გეგმა, დაფაზე და ტიტრებში ასეა მონიშნული.
- რეალური გაშვება (`tests/e2e/editorial-agents.mjs`, 17/17 PASS, `docs/editorial/evidence/agents/`):
  - მუსიკა: Claude Code-ის 1 მცდელობა უარყოფილი იყო (წაკითხვის სიჩქარე), მეორე მიღებულია; 4 ზუსტი ციტატა; 289 წმ.
  - ხელოვნება: მიღებულია პირველივე მცდელობით; 2 ციტატა; 619 წმ.
  - Claude-მა 3 კითხვიდან შეთავაზა შესაბამისი, injection-ი არა (21 წმ). Codex-მა უპასუხა მესამე პირში და თქვა, რაც არ იცის (19 წმ).
  - **ნაპოვნი და გასწორებული:** ორივე პირველ გეგმაში აგენტმა Q&A ბლოკში თვითონ დაწერა „მაყურებლის კითხვა“, ხოლო ხელოვნების გეგმაში — „ეს მაყურებელმაც იკითხა“. კარიბჭე ახლა ორივეს უარყოფს (`caac3fb`, `3848146`, ტესტით). ჩანაწერის გეგმა მესამე, ახალი გაშვებიდანაა და მიმდინარე კარიბჭეს გადის.

## 6. რა არის წინასწარ დამტკიცებული / ჩაწერილი

- ეთერის ტექსტი = პროდიუსერის მიერ დამტკიცებული გეგმის ზუსტი ვერსია (ჰეში მანიფესტშია). ეთერში აგენტი აღარაფერს წერს.
- ავტორის სეგმენტი = მისი ფაილი (ამ ტესტებში — სარეპეტიციო ტონი / სატესტო გამოსახულება), რედაქციის მიერ ზუსტ რევიზიაზე დამტკიცებული.
- **ხმა:** წამყვანები ჩანს მხოლოდ სუბტიტრებით. ტუჩები დახურულია და ეკრანზე წერია „მხოლოდ სუბტიტრები (ხმის გარეშე)“. ElevenLabs-ის ნიმუშები ამ ფორმატში არ გამოიყენება (მათი ტექსტი ამ შოუს არ ეხება). ფასიანი ზარი არ ყოფილა.
